# ChurchsProjection 标志设计简报

面向教会投影操作人员，用于 Windows / macOS 应用图标、仓库和启动界面。假设：项目名称沿用 ChurchsProjection；气质为清晰、安定、易用、开放；目前仅探索黑白形态。

## 概念探索

1. 光页：展开的经文页中用负形留出十字光隙。
2. 投影 C：字母 C 容纳向外传播的光束。
3. 共光：两块相向的屏幕框围合一个共享的中心。
4. 页角 P：用折角构成 P，缩小后易与文档图标混淆。
5. 光门：拱门与光带相融，容易接近建筑标志。
6. 经文行：三行文字化为投影光束，细节偏多。
7. 鸽翼：两翼承载经文页，宗教类别中较常见。
8. 讲台光：台面和光束组成图形，过于具象。
9. 共读圆环：围合的页面构成共同体，缩小辨识较弱。
10. 窗与书：屏幕边框与书页双重轮廓，层次偏多。

构建前三个方向。A 为推荐方向：负形十字直接关联基督信仰，开放书页关联经文；B 为字母标志；C 为抽象符号。仅研究参考库中几何及负形的处理方法，不复制其标志。

所有 SVG 为原创概念稿。黑白稿不依赖字体，预览标签为展示文字。未做商标检索，不承诺法律意义上的唯一性。方案选定后再制作配色、完整图标与使用规范。
