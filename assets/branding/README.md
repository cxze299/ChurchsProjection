# ChurchsProjection · 见证之窗

采用用户选定的第 05 号方案，屏幕边界与十字架组合，几何形状沿用已确认设计。

- `logo.svg`：蓝灰单色标志，透明背景。
- `app-icon.svg` / `app-icon.png`：蓝灰圆角底板、米白标志；PNG 为 1024 × 1024。
- `social-preview.svg` / `social-preview.png`：仓库分享图，1280 × 640。
- 主色 `#4E687B`；浅色 `#FAF7F0`。

标志外围至少保留一个十字架笔画宽度的空白，保持原始比例，不拉伸。
ICO、ICNS 和窗口 PNG 已同步到项目原有图标路径。
后续更改 macOS iconset 时，继续使用 `composeApp/tools/generate_windows_icon.py`
生成 Windows 与窗口图标。

GitHub 个人仓库没有独立头像；README 标志是项目标识。
